## 1. 一句话定位

单条视频端到端跑通 J1 旅程：`zhiying ingest <url>` → 下载 → 转写 → 画面识别 → 多模态文案（A1）+ 结构化摘要（A3），纯 Python CLI 形态，不含知识库与服务层。
