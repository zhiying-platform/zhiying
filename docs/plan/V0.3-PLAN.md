# 知映 zhiying — V0.3 实施计划（Web 前端）

> 状态：W1–W6 已完成（2026-11-10），W7 性能优化已完成；页面代码就绪待人工视觉验收
> 关联：`docs/PRD.md`（§5.5 V0.3 Web 交互流 / FR-303 / S12–S14）；本版本为 PRD §8 的 Web 交付。

## 1. 一句话定位

给 V0.2 的 API 服务配上浏览器界面：任务台（丢链接→看进度）、知识库（浏览/检索）、问答（带时间戳引用），覆盖 J1–J3 旅程操作路径（FR-303）。

## 2. 技术选型

| 项 | 选择 | 依据 |
|---|---|---|
| 框架 | Vue 3 + Vite（PRD FR-303 拍板） | 单页轻交互；团队既有 Vue3 技术栈积累 |
| 状态/路由 | Pinia + Vue Router | Vue3 标准组合 |
| UI 组件 | Naive UI | 轻量、TS 友好、中文文档好、无重主题依赖 |
| 服务层 | 直接调 FastAPI（`http://127.0.0.1:8600`） | 无需 BFF；开发期 Vite proxy |

| 前端工程 | **独立仓** `zhiying-web`（远端 `git@github.com:zhiying-platform/zhiying-web.git`） | 对齐既有惯例（gewu/gewu-web 等四项目均前后端分仓）；工具链与部署目标差异大（DR-21）|

> 前端工程位于独立仓 `zhiying-web`（对齐 gewu / gewu-web 等既有项目结构）；前后端仅通过 REST API 通信，不共享代码。

## 3. 任务拆解

| Step | 任务 | 验收 |
|---|---|---|
| W1 | 脚手架：Vite + Vue3 + Pinia + Router + Naive UI | `npm run dev` 可打开 |
| W2 | API 客户端层（fetch 封装 + 4 域） | 类型化调用可通 |
| W3 | 任务台页 | 粘贴链接→提交→任务卡片实时进度→失败重试 |
| W4 | 知识库页 | 视频列表（主题标签筛选）→ 详情（摘要/分段/时间戳） |
| W5 | 问答页 | 提问→回答+引用角标→引用点击展开原文 |
| W6 | 代理与启动脚本 | `zhiying web` 一键起（API+前端），CORS 配置 |
| W7 | 长视频 visual 阶段性能优化 | ✅ 17min 视频 >12min → **11s**（提速约 65×）|

## 实施记录（2026-11-10）

| Step | 交付 | 验收 |
|---|---|---|
| W1 | Vite+Vue3+TS+Naive UI+Pinia+Router 脚手架 | `npm run build` 通过（2681 模块/505ms）|
| W2 | `api/client.ts` 类型化客户端 | tasks/search/ask/videos 四大域 |
| W3 | 任务台 TaskConsole | 提交/轮询/阶段标签/409 幂等提示 |
| W4 | 知识库 KnowledgeBase | 列表/关键词筛选/主题标签/摘要详情 |
| W5 | 问答 AskView | 问答/引用标签/引用原文折叠/无依据警告 |
| W6 | 代理与启动 | vite proxy `/api` → 127.0.0.1:8600（双侧 200）|
| W7 | 长视频优化 | ≥10min 改 ffmpeg 定点 seek 采样 |

**联调验证**：前端 5273（显式绑 IPv4）+ 后端 8600；`/api/health` 与 `/api/videos`（真实知识库数据）经代理均 200。

**W7 实测结论（重要）**：长视频瓶颈是 **OpenCV 逐帧解码**（17min/204MB 即使 `frame_skip=2` 仍 >12min），不是检测算法。改为 ≥10min 直接跳过场景检测、用 ffmpeg `-ss` 定点采样（不依赖前置帧解码，O(1) 级）：**17 帧/10.8s**。短/中视频仍用 PySceneDetect（切点更准）。

**未完成**：浏览器视觉验收被策略拦截（`browser navigation blocked by policy`），页面渲染效果需人工打开确认。

## 4. Non-Goals

- 移动端适配（V1.0 触发制）
- 登录/鉴权（单用户阶段，DR-19 零登录）
- SSE（先用轮询，进度粒度到阶段级已足够）

## 5. 决策记录

| 日期 | 决策 | 依据 |
|---|---|---|
| 2026-11-10 | 前端放**独立仓** `zhiying-web`（对齐既有项目惯例） | 工具链/部署目标/依赖树全不同；四项目既有惯例均分仓；作品集叙事更清晰。代价（契约变更需双仓协调）由 FastAPI `/openapi.json` 作为合同缓解（DR-21） |
| 2026-11-10 | 进度更新用轮询而非 SSE | 单用户场景轮询 3–5s 已够；SSE 复杂度延后 |
| 2026-11-10（DR-26） | 任务删除改两档：清除记录（默认，仅 task/meta，保留知识库与源视频/产物）/ 彻底删除（KB 级联+工作目录，红色警示）；不做定期自动清理，推荐手动 | 用户纠偏「删除应只清任务记录而非全量数据」；单用户场景手动可控性最优，自动清理误删风险大；源视频保留（重处理/帧提取/播放需要），文件存储服务（MinIO 等）暂不接入——本地磁盘在单机阶段够用，多机部署时再评估 |
