## 实测坑记录（构建管线）

1. **PG18 与 pgvector 0.8.0 不兼容**：`vacuum_delay_point()` 签名变更 → 用 v0.8.7（0.8.4+ 支持 PG18）
2. **embeddable Python 无 pip**：用开发 venv 的 pip `--target` 预装（同版本 3.12 win_amd64 二进制兼容）
3. **`--target` 安装丢 .pth 引导**：site-packages 必须放 `python\Lib\site-packages` 标准布局（site 扫描才处理 .pth）；zhiying 源码用 `zhiying-src.pth`（`..\..\..` 三级向上）引导
4. **mcp 依赖 pywin32**：wheels 清单必须含 pywin32（pywintypes 由 bootstrap 加载）
5. **ps1 脚本必须 UTF-8 BOM**（PS5 无 BOM 按 GBK 读炸）；cmd 脚本必须 GBK+CRLF（见 windows-cmd-batch-scripts 技能）
6. **ISCC LZMA2/max 压 640MB 慢**（~15 分钟）：安装包体积优先，等待即可

## 安装/卸载性能优化（实测驱动）

老板反馈：每次安装/卸载都要 20 多分钟，体验不正常。实测拆解后定位根因：

| 环节 | 优化前 | 优化后 | 改善 |
|---|---|---|---|
| stage 文件数 | 26,918 | 6,823 | **-75%** |
| stage 体积 | 1,262 MB | 539 MB | -57% |
| 安装包体积 | 336.5 MB | **141 MB** | -58% |
| 构建编译耗时 | 1,005 s | **370 s** | -63% |
| **用户端安装耗时** | 3.3 分钟 | **69 秒** | **-65%** |
| 用户端卸载耗时 | 6 秒 | 3.4 秒 | -43% |

**根因**：EDB PostgreSQL 二进制包自带 `pgAdmin 4`（16,878 个文件 / 676 MB 图形管理工具）+ `StackBuilder`，占全部文件的 63%——知映只用 PG 服务端，两者完全用不到。

**其它优化**：
- 构建期清理 stage 内 `__pycache__` / `.pyc`（3,203 个，运行时自动重建）
- 移除 `*.pdb` 与 `LICENSES.chromium.html` 等大体积无用文件

> 注：早期「20 多分钟」的另一种来源是**开发期重新编译安装包**（ISCC LZMA 压缩），与用户端安装体验无关；裁剪后编译降到 6.2 分钟。
