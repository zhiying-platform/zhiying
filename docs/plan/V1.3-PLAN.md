# V1.3 计划 — 项目整体 UI 与 Logo 优化设计

> 状态：已交付（2026-11-17）｜ 前置：V1.2.1（安装器与体验优化已交付）｜ 实施记录见本文末尾

## 目标

功能链已通（V0.1→V1.2.1），下一版本聚焦**视觉体验**：项目整体 UI 风格统一 + 专属 Logo 设计，让「知映 zhiying」具备可识别的产品形象。

## 范围

### 1. Logo 设计
- 主 Logo：知映品牌标识（知识 + 映射/视频 → 知识的意象），含横版（带字）与方版（纯图形）
- 多场景适配：favicon（ico/png）、Windows 安装器图标、托盘图标、桌面快捷方式、dmg 卷标（暂缓 mac 发布）
- 配色基线：主色、辅色、中性色刻度化；暗色模式预留（当前前端为亮色）

### 2. Web 端 UI 优化
- 侧边栏/顶栏/卡片/按钮/表格/状态标签的样式统一（当前 naive-ui 默认样式偏"能用到"而非"产品化"）
- 任务台：任务卡片层次、进度条/统计卡片视觉强化、失败态更醒目
- 文档库 / 知识库 / 问答 / 设置页风格一致
- 响应式与留白、字号层级、图标语义统一（现用 emoji，考虑替换为统一图标）

### 3. 安装器视觉
- 中文向导页视觉（Inno 默认向导皮肤较朴素）
- 卸载/升级弹窗文案与此一致

## 决策记录

| 决策 | 内容 | 依据 |
|---|---|---|
| DR-50 | V1.3 聚焦 UI 与 Logo，不新增业务功能 | 用户拍板：功能已通，下一版本做视觉 |
| DR-51 | Logo 与前端资源入仓（矢量源 + 导出物），安装器引用同一套资源 | 避免多处图标不一致（历史教训：托盘/快捷方式图标曾各自为政） |

## 交付物（已交付）

- `assets/logo/`：印章 SVG 矢量源（fix_seal.py 像素级重建）+ PNG/ICO 导出物 + 横版 Logo
- `zhiying-web/`：Icon.vue 内联 SVG 图标组件（Lucide 风格）、全仓 emoji 清零、侧栏展开横版 Logo / 折叠印章
- `installer/setup.iss`：安装器图标与向导视觉（wizard-large/small 印章同调）
- 验收：Web 各页风格统一、Logo 全场景一致（favicon/托盘/安装器/桌面）、亮色模式无视觉断点；seal 修正版已同步前端 favicon/侧栏与安装器 stage
