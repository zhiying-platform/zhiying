# V1.4 计划 — 朱砂批注主题（Web UI 设计语言升级）

> 状态：已交付（2026-11-26）｜ 前置：V1.3.2（设置页表单标签修复）｜ 实施记录见本文末尾

## 目标

V1.3 完成品牌视觉统一后，Web 端仍是 naive-ui 默认蓝主题，与印章 Logo 的朱砂红断裂。本版本建立「朱砂批注」设计语言：纸白底、墨色文字、朱砂红只给语义（时间戳/可回跳/当前阶段），并重设计任务台空态为「卷首语 + 管道时间线」，补齐首用引导。

## 范围

- `zhiying-web`：App.vue 主题令牌（naive-ui common.primaryColor → #B03A2E 全套 hover/pressed）、style.css 清 Vite 脚手架残留并建立 --paper/--ink/--cinnabar 设计令牌、TaskConsole 统计卡语义色纪律（0 值灰化）+ 空态重设计 + 运行态标签/进度条朱砂化、AskView Q 标色同步
- 明确不改：业务接口、数据结构、其他页面布局骨架

## 决策记录

| 决策 | 内容 | 依据 |
|---|---|---|
| DR-60 | 三方向门选定「A 朱砂批注（色/语义）+ B 卷首语（空态嗓音）」混合方向 | 三方向盲选流程（interface-as-world 方法论），用户拍板混合 |
